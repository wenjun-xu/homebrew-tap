# TokenFlow Homebrew Tap

GitHub Copilot CLI 本地只读 Token 用量 Dashboard 的安装源。

```bash
brew install wenjun-xu/tap/tokenflow
tokenflow start
tokenflow stop
```

Homebrew 自动管理 Python，无需手动配置。升级或卸载前先执行 `tokenflow stop`。

当前为 `0.1.0` 预发布版本，仅支持可验证 `sandbox-exec` 隔离的 macOS；
Intel、其他 macOS 版本及干净机器安装尚未完成全面验收。

源码与发布包：[wenjun-xu/TokenFlow](https://github.com/wenjun-xu/TokenFlow)。
